# 拆解填写指南

- **钩子类型**：痛点（"打不远？"）/ 反常识（"握杆越紧越差"）/ 结果展示（先放成品）/ 提问 / 身份标签（"零基础女生"）/ 价格锚点。
- **结构归纳**：用箭头写出段落功能，如 痛点→示范→纠错→对比→CTA；标注每段时长占比。
- **卖点**：区分「信息价值」（学到什么）、「情绪价值」（向往/安心）、「信任状」（资质、案例、数据）。
- **CTA**：原片是否有明确动作（关注/私信关键词/评论区/预约），位置在开头还是结尾。
- **改写适合度**：1-5 分；5=结构可直接复用，只换自家素材。
- **受众适配**：按 config 的受众占比加权，给出最值得投入的 1-2 个人群。
- **合规**：不复制原文和画面；价格、活动等事实以自家已确认资料为准。
